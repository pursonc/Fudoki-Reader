# Changelog

## 1.1.3

- Translate the original Japanese sentence without injected readings or short meanings.
- Locate sentences from the clicked word's exact source position, including repeated words.
- Use the same clean sentence extraction for selection-popup translations.

## 1.1.2

- Open the optional Google Forms feedback survey after the extension is uninstalled.
- Send no extension identifiers or usage details with the uninstall survey link.

## 1.1.1

- Remove unused `activeTab` and `tts` permissions.
- Limit background network access to the optional Google translation service.
- Correct Chrome Web Store permission disclosures for local text analysis.
- Add a public privacy policy covering local storage, translation, feedback, and support links.

## 1.1.0

- Add inline Japanese readings with hiragana, katakana, and romaji modes.
- Add mutually exclusive word and sentence translation modes.
- Add a compact right-side reading toolbar with instant page re-rendering.
- Restore selection-based speech controls, word highlighting, part-of-speech labels, translation, and vocabulary saving.
- Add no-login feedback and Wise support links.
- Limit page processing to Japanese content and exclude links and interactive controls.
- Add an update badge and in-popup version notice for existing users.
- Keep the right-side toolbar and selection reader in sync with the selected interface language.
- Apply light, dark, and system themes consistently to webpage controls and translation bubbles.
- Reduce the release package by excluding unreachable legacy reader assets.
